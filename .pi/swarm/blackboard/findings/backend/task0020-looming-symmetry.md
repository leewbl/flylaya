# TASK-0020 · 连接组 looming→yaw 左右对称性修复(H2 左镜像阻断)

backend · 2026-09-26 · 依据: m5/report/sem-phase2-report.md §归因 · 改 flylaya/brains.py(读出侧)+ m5/runner.py + m5/metrics.py(检测器事件时钟)

## 根因(两层,探测实锤)

1. **符号盲的内核暗反射**: 镜像姿态探针(侧车全关)——左前柱 −14.6 Hz、右前柱 −15.1 Hz,同号。内核对剪影的方向响应不分辨左右;修复前的"右柱正确转离"其实是均匀光强紧张性偏置(+6~8 Hz 持续左转)碰巧朝向正确侧。
2. **均匀照度紧张性偏置随亮度变化**: 0 均值标定的 DC 扣除在 0.45 均匀场下残留 +6~8 Hz(≈150°/s 左旋)。另发现: 同均值下"均匀暗场"与"图案暗 patch"的内核响应**反号**(uniform 0.25 → +17 Hz vs 暗 patch → −17 Hz)——按亮度水平的查表扣除在剪影下会加倍误差,必须按场对比度门控。

## 修复(全部读出侧)

1. **照度水平偏置扣除**(仅近均匀场, contrast<0.15): init 时 0/0.2/0.45/0.7/1.0 五级均匀场标定 DNp20(R−L) 紧张性,逐帧按均值亮度插值扣除。
2. **looming 抑制器**: 剪影存在时(前野暗占比 frac>0.15 或近场前/后亮度比崩溃)按 frac 线性衰减内核 yaw 通道(至 5%),把方向命令交给对称侧车。
3. **对称 looming 侧车**: 前野暗重心指向逃离(近场探测器塌缩时用前野左右半亮差定向),近距增益放大,输出硬限 ±8 Hz。
4. **检测器事件时钟**(m5/metrics.py + runner): detect_events 重放 scene 事件时间线,按帧时刻判定柱可见性——修复 runner 用 run 末 enabled 状态回放全部帧造成的**刺激前幻影接近窗**(右镜像 3/3 假事件源)。

设计取舍记录: 亮残差(remnant)体制与定时锁存逃逸转向试验后**移除**——近场均匀暗场下"残差"退化为感受野固定几何偏置,两侧同号(+30/+30 探针),锁存放大成共模回旋。
