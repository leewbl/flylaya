# FlyLaya 下一轮实验系统设计：验证意图能否经连接组产生目标行为

> 版本：v1.0 · 2026-09-25 · 状态：可交付开发的实验设计，尚未执行  
> 研究对象：Laya（Jev 兼容的开源 System One 决策模型）× MaleCNS 果蝇连接组仿真  
> 范围：设计、实现接口、实验与验收；本文件不宣称下一轮结果已经成立。  
> 上轮证据：[研究交接](flylaya-research-handoff-llm.md)、[三口径终报](flylaya-final-report.md)、[文献基线](../../m3/literature_baselines.md)。

## 0. 一页结论

下一轮不以「做一个更漂亮的 3D 果蝇」为研究目标。它要回答三个可独立判定的问题：

1. **语义有效性**：Laya 看到前方障碍或侧向光源时，是否比行动频率匹配的无状态意图序列更常选择合适目标？
2. **神经通路有效性**：被选择的目标是否经视觉输入、连接组活动和下行神经元（DN）读出，产生方向正确的动作？还是主要由连接组外的推力、噪声和直接偏航规则造成？
3. **行为拟真度**：修复接口后，快速转向、趋向、避障和垂直运动是否更接近条件相近的真实果蝇数据？失败时能否定位到感觉编码、决策、神经读出或身体映射？

系统采用两类 3D 资产：**实验世界**规定光、障碍和碰撞，参与因果过程；**观察器**只从同一实验记录渲染轨迹，不能偷偷改变模型输入。可换画风与模型外观，但任何影响感官或动力学的改动都必须形成新版本、新批次。

## 1. 为什么需要下一轮

现有系统已经闭环运行：状态文本 → Laya `choice`/`score` → 感官增益及运动参数 → 连接组 LIF → DN 读出 → 位姿。[`intent.py`](../../flylaya/intent.py)、[`server.py`](../../flylaya/server.py)、[`world.py`](../../flylaya/world.py) 是实现基线。

上轮的限制直接决定本轮任务：

| 已知现象 | 下一轮必须回答的问题 |
|---|---|
| 旧 A 盲评 59/60 被选，但 `avoid_obstacle` 占 98.9%；修正后 A−B 速度 KS D 从 0.394 降到 0.178 | 观察者偏好来自状态相关选择，还是几乎一直运动？新版 A 必须重新批量与盲评 |
| 连接组组的旧 `sun_R` 约 0.04，骨架脑约 0.53 | 方向信息在视网膜编码、连接组传播、DN 读出，还是运动映射的哪一段丢失？`sun_R` 本身不是趋光方向指标 |
| 旧 B 固定每 3 秒切换，D 每 300 毫秒随机；A 的停留时间又不同 | 旧 B/D 不能作为严格的「只改变决策内容」对照；应匹配意图频次、持续时间和唤醒度 |
| 真实果蝇快速转向常为约百毫秒，主轨迹日志只有 10 Hz | 10 Hz 数据不能可靠证明转向持续时间或峰值角速度；短程机制实验要提高神经与运动记录分辨率 |
| `sun_R` 是相对太阳角度的**集中度**，即使一直背向太阳也可能很高 | 趋光主指标改为朝向太阳的有符号量，同时报告 `R` 和平均方向 |
| 当前 Laya 状态文本读取障碍坐标、太阳方向、位置等世界真值 | 需要区分「上帝视角状态」的能力上限与「仅可观测状态」的真实闭环能力 |

在新参数 40 段重批和新版 A 盲评完成、归档前，旧版 98.3% 只能作为历史结果。运行中的目录不能充当冻结基线；分析须引用批次清单和哈希。

## 2. 研究主张与预注册判据

本轮的主张按强度递进，不可用较弱证据替代较强主张：

| 等级 | 可主张内容 | 必需证据 |
|---|---|---|
| L0 | 系统工程闭环可运行 | 可复现轨迹、完整日志、无静默回退 |
| L1 | Laya 提供状态相关的意图选择 | 相同场景/种子下优于匹配意图分布与停留时间的 yoked 对照；前后、左右刺激翻转响应正确 |
| L2 | 意图经连接组通路影响行为 | 仅感官/神经通路条件仍有正确方向的 DN 变化及动作；关闭直接偏航与后神经运动捷径后效应保留 |
| L3 | 更接近真实果蝇 | 条件匹配的真实轨迹/文献多指标改善，新版真实参照盲评支持，且无关键指标退化 |

**确认性假设**（阈值是本项目的工程判据，并非文献给出的果蝇常数；先完成探索性试跑，再锁定阈值、场景和代码，之后才运行确认批）：

- **H1 光方向**：在左右镜像的单光源场景中，Laya 的每段平均 `cos(航向与目标方向夹角)` 相对 yoked 对照的配对差至少 `+0.15`，跨独立种子的 95% 区间下界大于 0；两侧镜像均成立。未满足则不宣称意图内容带来趋光增益。
- **H2 避障**：在前侧障碍场景中，Laya 的每次有效接近事件碰撞风险相对 yoked 降低至少 25%，跨种子区间上界低于风险比 1；后方障碍负对照中不应持续触发避障。若事件太少，先报告转离方向、最小间隙和接近事件数，不把空分母解释为成功。
- **H3 神经中介**：在关闭直接 `yaw_bias` 和后神经推力/噪声差异后，预先指定的 DN 左右读出对镜像刺激应呈镜像变化，并与转向同号；仅有位姿变化而无相应 DN 变化，只能归入工程控制效应。
- **H4 拟真进展**：快速转向率/幅值/持续时间和速度与**场景匹配**的真实数据逐项比较；不能用一个加权总分掩盖退化。文献近似范围是外部参照，不是调参目标函数。

H1、H2 是行为层两个共同主终点，确认批分别报告效应量和区间，若做显著性检验则按两个终点控制多重比较。H3 是解释 L2 主张的必要门槛。H4 是独立的生物学评价；负结果也是完整交付。

## 3. 系统边界与因果结构

```text
场景规范 + 独立随机流
   ├─ 世界真值 ────────────────────────────────────────────────→ 评分器（只读）
   ├─ 感官渲染 → 视网膜亮度/可观测量 ─→ MaleCNS LIF ─→ DN ─→ 运动映射 ─→ 位姿
   │                    │                                       ▲                 │
   │                    └─ 可观测状态编码 ─→ Laya choice/score ─┤                 │
   │                                          │                  │                 │
   │                                          └─ 感官/神经调制 ───┘                 │
   └─ 上帝视角状态编码（仅能力上限组）─────────────────────────────→ Laya             │
                                下一轮从位姿与感官再入闭环 ◄─────────────────────────┘

独立观察器：读取已冻结轨迹与场景 → 双视窗回放/盲评；不参与上述闭环。
```

### 3.1 两种 Laya 状态，不混称

- `oracle_state`：沿用现有 `state_text(world, …)`，可读精确障碍/太阳/位置。用途是诊断上限和检查意图词表；结果只能说明有真值辅助的外部控制。
- `observable_state`：只由视网膜亮度空间摘要、可用的神经群/DN 读出、速度或姿态估计及意图历史组成；禁止直接读障碍实体位置、太阳真方向、场地种子或评分器标签。其第一版允许明确标注的机体自感估计。状态编码须记录每个字段的来源与延迟。

优先把 `observable_state` 做成有限、可审计的结构化字段，再格式化成 Laya 文本。世界真值只在评分与调试日志中出现。若 MaleCNS 暂时缺可用的内部感官读出，可先从同一视网膜亮度向量提取左右/上下对比和暗扩张线索，明确称为「感官可观测版」，不要称为「纯神经状态版」。

### 3.2 三条调制通路必须分开记录

1. **前神经感官通路 `sensory`**：现有 `light`、`looming`、`wall` 改变亮度向量。这是当前最直接的 Laya→连接组接口。
2. **神经读出后的 `motor` 通路**：现有 `thrust`、`yaw_noise` 改变运动。它能改变轨迹，却不能单独证明信号经连接组传播。
3. **直接覆盖 `direct`**：切入避障时的 `yaw_bias` 等直接偏航。机制实验默认关闭，安全演示条件可以开启并单列。

同一意图允许 `sensory_only`、`motor_only`、`full` 三种耦合模式。主张 L2 时，以 `sensory_only` 为核心；`motor_only` 是捷径对照。所有调制都要在日志中带 `source_path`、数值和起止时间。不得把直接偏航造成的避障算作神经通路成功。

更深一层的结合可增加 `neural_targeted` 研究臂：让意图调制经注释确认的特定神经群输入或兴奋性，而不是只改视网膜亮度。当前 MaleCNS `Sim.step` 主要接收视网膜亮度与少数固定刺激，尚无通用、已验证的神经群调制接口；因此这项需先核对细胞注释、刺激单位、对照神经群和无意图时的稳定性，再单独立项。不能把随意修改 DN 频率当成连接组内部调制成功。它不阻塞本轮 `sensory_only` 主实验。

### 3.3 时间尺度

- Laya 决策保持约 300 ms 的默认节奏，记录请求/响应时间、原始概率、应用意图、滞留护栏和回退原因。
- 开放场景可先沿用 100 ms 生物帧作吞吐基线。
- **快速转向短程实验**需试运行 10–20 ms 神经推进与同分辨率 DN/姿态记录。仅把 100 ms 的同一 DN 指令细分积分，不能算提高了神经时间分辨率。先做 10 秒性能冒烟；若内核无法支持，明确降级为「10 Hz 粗事件计数」，不报告峰值/持续时间结论。
- 不要求第一轮引入完整翼拍或 MuJoCo 身体物理。若以后引入，作为独立 `body_model_version`，重新建立基线。已有研究说明真实飞行身体模型需要独立的物理和控制标定，不能由连接组接线图自动给出。[Vaxenburg 等，Nature 2025](https://www.nature.com/articles/s41586-025-09029-4)

## 4. 3D 实验场景规范

在保留 1 m 立方空间坐标与现有渲染链的前提下，新增场景清单；每个场景均有镜像、负对照和独立随机流。确认批不在跑到一半后改几何或阈值。

| 场景 ID | 几何与刺激 | 主用途 | 必做对照 |
|---|---|---|---|
| `S0_neutral` | 无柱、均匀照明、起点在中心；同一初始高度/速度分布 | 自发转向、DN 基线、z 运动 | 无 Laya 调制；左右镜像起始航向 |
| `S1_light_left/right` | 无柱，单侧方向光；两侧严格镜像，固定强度与高度 | H1：目标方向是否从输入传至 DN 和轨迹 | 光源左右翻转、平光条件、`phototaxis`/`explore` 固定意图 |
| `S2_obstacle_left/right` | 单柱在前方 20–40 cm、相对航向 ±20–35°；起始速度非零 | H2：避障选择与正确转离 | 左右翻转；等距后方柱负对照；无柱对照 |
| `S3_wall` | 靠近单壁或角落，其他线索中性 | 回中行为与墙反射 | 对向镜像、远墙对照 |
| `S4_mixed_holdout` | 光、柱、壁同时存在；几何种子与探索批不重合 | 泛化、场景冲突与新版盲评 | 固定/匹配 yoked/手写规则；不同初始朝向 |

测试时场景应有**诊断窗口**，如前 5 秒基线、之后刺激开启或移动、随后观察 10–30 秒。对于受控刺激，必须能记录开关与方向。紧急的直接避障安全逻辑若启用，不能覆盖「碰撞前状态」日志。

场景文件建议使用现有 JSON 风格，不新增依赖。示意合同：

```json
{
  "schema_version": "flylaya.scene.v1",
  "scene_id": "S2_obstacle_left",
  "arena_m": [1.0, 1.0, 1.0],
  "duration_s": 30,
  "decision_dt_s": 0.3,
  "neural_dt_s": 0.1,
  "start": {"position_m": [0.5, 0.25, 0.5], "yaw_deg": 90, "speed_m_s": 0.12},
  "light": {"mode": "uniform"},
  "obstacles": [{"id": "o1", "shape": "cylinder", "center_xy_m": [0.43, 0.52], "radius_m": 0.04, "height_m": 0.65, "enabled": false}],
  "events": [{"t_s": 5.0, "kind": "stimulus_on", "target": "o1"}],
  "mirror_axis": "x",
  "random_streams": ["scene", "controller", "neural", "motor"]
}
```

解析器应拒绝单位缺失、越界柱体、同 ID 重复和互相矛盾的采样周期。镜像变换要同时作用于几何、起始姿态和预期动作符号，不能只翻转回放镜头。按 `scene_id + seed + version` 应得到相同场景；场景随机数不与 Laya 采样或运动噪声共用一个 RNG。场景、轨迹、回放三处的坐标和长度单位由一份转换函数统一。

## 5. 决策组与消融矩阵

### 5.1 必要的决策组

| 组 | 策略 | 解决什么混杂 |
|---|---|---|
| `P_laya` | Laya 原始概率 + 已声明的温度/探索策略；同时保留原始 `argmax` | 完整候选组 |
| `P_yoked` | 从对应 Laya 运行得到的意图和唤醒度序列，按预先确定的块置换/循环位移施加到同种子场景；保留各类占比、停留长度和幅度，打乱与当前状态的对应 | 区分「状态相关选择」与「有相同活动量的序列」 |
| `P_rule` | 可解释的几何/感官规则：前方近障碍→避障，近壁→回中，其余在指定光场景→趋光 | 校验场景可解性、给工程上限；需标注是否使用真值 |
| `P_fixed` | 固定目标，仅在单线索机制实验使用 | 测单个目标到神经/运动的传递函数 |

`P_yoked` 的序列在成对的 `P_laya` 跑完后冻结，再用于同一初始场景/种子；置换规则预先固定并验证分布、平均滞留和唤醒度与源序列一致。闭环轨迹随后会分叉，这是要测试的状态依赖效应，不应强制两组走相同位姿。旧版均匀随机组可作附加展示，不能代替 matched yoked 主对照。

### 5.2 最小确认矩阵与顺序

1. **接口诊断**：`S0–S3` × `P_fixed` × 连接组/骨架脑，分别测 `sensory_only`、`motor_only`；目标是定位传输瓶颈，不作 Laya 优势统计。
2. **语义确认**：`S1` 左右、`S2` 左右/后方 × `P_laya`、`P_yoked`、`P_rule` × 连接组；固定 `observable_state`，以 `sensory_only` 为主条件，`full` 只作另列的系统效果条件。镜像与种子配对。H1/H2 用这一批判定。
3. **中介确认**：在第二步可见效应的场景上，保持意图序列，关闭 `direct`，比较 `sensory_only`、`motor_only`、`full`；必要时引入神经读出静默或视觉左右翻转。H3 用这一批判定。
4. **开放场景**：通过前述诊断后，再在 `S4_mixed_holdout` 比较三组 300 秒轨迹，开展与真实样本的盲评。若前述失败，开放场景可以运行作失败形态展示，但不声称 L2/L3。
5. **Jev 真模型**：仅在 API 可用且得到同一输入、同一候选词表和同一采样协议时作为独立扩展组。Laya 的结果不自动外推到 Jev；该组不阻塞主实验。

`oracle_state` 与 `observable_state` 分开成批。先用前者调通接口和诊断上限，确认性 H1/H2 以锁定的 `observable_state` 为准；如果只做前者，结论降级为外部真值辅助控制。

## 6. 数据合同与可复现性

每个 run 至少产出：

- `manifest.json`：`experiment_id`、schema/代码/模型/权重哈希、连接组数据版本、场景原文哈希、策略/调制/检测器版本、种子及四条 RNG 流、设备、时间步、起止时间、成功/失败状态、来源批次。缺字段不得进入确认性汇总。
- `trajectory.jsonl`：逐帧时间、位姿、速度、碰撞前的间隙、刺激事件、原始与应用意图、唤醒度、前/后神经增益、直接偏航量、关键 DN 左右读出。高频事件另存 `neural_events.jsonl` 或紧凑二进制，保证时间戳同源。
- `decisions.jsonl`：每次 Laya 请求的状态来源/文本哈希、原始 `choice` 概率和 `score`、抽样/滞留决策、延迟、超时/回退原因。原始概率与施加温度后的采样概率分列；不能把后者说成模型的校准概率。
- `events.jsonl`：接近障碍起止、转向开始/结束、障碍接触（位置夹回前）、墙接触、失去太阳可见性等。事件检测版本固定。
- `metrics.json` 和 `report.md`：每段指标、每场景/种子的配对差与区间、排除理由、缺失率、负结果。旧 M3 指标可兼容，但不能覆盖其旧计算口径。

应流式写文件，避免当前 `m4/run_batch.py` 一次把全段 `rows` 保存在内存。连接组实例在 16 GB 机器上先按串行运行；失败 run 必须有明确状态，不允许因已存在输出文件就静默跳过半成品。断点续跑按 `manifest` 与文件完整性验收，而非只检查文件名。固定种子复跑允许对浮点平台差异设容差，并记录平台。

## 7. 指标定义与统计单位

| 类别 | 指标 | 解释与陷阱 |
|---|---|---|
| 决策 | 条件命中率、前/后障碍误报、切换率、各类占比、平均停留、超时/回退 | 不把「意图多样」本身当作正确性；需对照刺激标签和时序 |
| 光方向 | `mean_cos_to_light = mean(h_xy · target_xy)`、朝目标位移、首次正确转向延迟 | 取值 −1 到 1；`sun_R` 仅作集中度，必须联报平均方向，不能单独解释为趋光 |
| 避障 | 每次有效接近的接触率、最小间隙、正确转离率、反应延迟 | 有效接近须先满足距离、前方角与相对闭合速度；分母先固定；碰撞以夹回/推出之前判定 |
| 神经中介 | 刺激前后预指定 DN 差值变化、符号一致率、神经变化先于转向的比例 | 与无调制及镜像刺激比较；报告直接通路造成的动作份额 |
| 飞行 | 转向率、幅值、持续时间、峰值角速度、速度分布、z 分布、休息、墙边停留 | 只有高时间分辨率组可报告转向持续时间/峰值；开放场景指标按各条件分层 |

统计的独立单位是**场景内独立种子/飞行段**，不是 10 Hz 帧，也不是重复看同一轨迹的评分次数。用同种子配对差、分层 bootstrap（先抽种子，再抽场景；盲评再抽评分者）报告 95% 区间；池化帧的 KS D 可作分布描述，不能以其帧级 p 值作为主要因果证据。`P_laya` 与 `P_yoked` 的原始意图分布、停留和唤醒度差距若超过预设匹配容差（建议各类占比绝对差 ≤0.02，平均停留相对差 ≤10%），该配对不得进入主分析，须修正生成器后整批重跑。

场景几何、光照和真实文献若不匹配，只报告相对改进；真实果蝇范围不是跨所有场景通用的合格线。当前速度 `[20,60]` cm/s 与直度 `[0.6,0.95]` 仍含推断，不能写成已验证的硬性生物学门槛。[本地基线说明](../../m3/literature_baselines.md)。

### 7.1 样本与冻结规则

- 开发期：每个单线索条件先 1 个种子 × 10 秒冒烟，再 5 个种子 × 30 秒探索性试跑。探索期可改场景、模型提示与阈值，但每次必须换版本。
- 确认期：锁定场景、提示、模型权重、温度、接口、指标、排除规则；使用**未参与探索的至少 20 个种子**，镜像条件各自成对。预算受限时先完成 H1，再完成 H2，不能跑到结果显著即停止。
- 300 秒开放场景：先按旧批成本试估，再确定种子数并写入冻结清单；建议至少 10 个未见种子/组。若时间或内存不足，减少场景组数并记录，而不是减少某组种子造成不平衡。
- 文献/真实轨迹参照应记录物种、性别、状态、光照、场地尺寸、采样率、转向检测规则。尽可能取得公开原始轨迹；若仅有文献摘要，只作数量级参照。

## 8. 3D 观察器与人类盲评

观察器从冻结的场景及轨迹清单生成，不重新仿真。支持俯视/侧视、统一比例尺、同步时间轴、刺激事件层、DN/意图图层、左右镜像切换。**科研盲评模式**隐藏配置名、意图、DN 与数值；**诊断模式**展示这些信息。两模式可用同一回放引擎，权限和导出分开。

新版盲评至少包含两个问题，不能混为一个分数：

1. **任务判断**：哪段更明确地趋向目标或避开前方障碍？此项无需真实果蝇参考。
2. **生物拟真判断**：在提供同场景、同镜头、同速度的真实果蝇轨迹参考后，哪段整体更接近真实轨迹？若真实参考无法获得，就只报告「模拟方案间的人类偏好」，不称绝对拟真。

评分者不得看到文件名、真假标签或参数；左右随机，配对种子和场景一致，每位评分者顺序不同。不要从旧页直接复用能在前端数据中暴露 `truth` 的文件作正式盲评：真值由服务端/离线清单保管，评分页只收到匿名片段 ID。预设训练题、评分说明、每位评分者的独立选择与 5 点分、原始一致率及 AC1；κ 可附报并解释边际偏斜。重复使用同一轨迹时，统计需按轨迹和评分者聚类，不能把所有点击当独立实验。

展示层视觉风格可以更新，但正式盲评前冻结相机、果蝇尺寸、光照、轨迹尾迹、播放帧率和渲染配置；真实样本若为视频而非三维轨迹，需单独说明视角/材质无法匹配，优先做定量参照，避免凭画风评判拟真。

## 10. 预期的解释分支

| 观察到的组合 | 应如何解释 | 下一步 |
|---|---|---|
| Laya 意图随刺激正确变化，但 DN/轨迹不变 | 决策层可用，感官→神经或 DN→身体接口不通 | 查左右视觉信息、DN 选择、基线扣除、调制深度 |
| DN 正确变化，但转向方向不对或太慢 | 运动读出/时间常数问题 | 单独标定 DN→偏航增益与快速通道 |
| `full` 有效、`sensory_only` 无效 | 主要是后神经参数或直接规则在起作用 | 明确降级为工程控制；重新设计神经内耦合 |
| Laya≈yoked，且两者都比固定组好 | 序列频次/唤醒度有用，尚无状态语义增益 | 改状态可观测性、意图定义或模型专门化 |
| `oracle_state` 有效、`observable_state` 无效 | 需要更好的可观测感官/内部状态表示 | 补视觉运动/深度估计与神经群读出，不把上帝视角称生物闭环 |
| Laya 在简单场景胜出，混合场景失败 | 策略冲突或泛化不足 | 加入多线索冲突任务与未见场景验证 |
| 相对对照有效，但真实转向仍差很远 | 组合架构局部成立，绝对拟真未达 | 改时间分辨率、身体映射、匹配真实数据与环境 |

## 11. 研究依据与口径

- TypeSafe 将 Jev 定义为输入状态、输出类型化概率决策的 System One 模型；Laya 提供兼容接口。本项目检验的是 **Laya 在果蝇闭环中的表现**，不是 Jev 本体的效果：[TypeSafe 官方介绍](https://typesafe.ai/blog/introducing-system-one-models-and-jev)、[Laya 项目](https://github.com/LeonaDavinci/laya-system-one)。Laya 项目也提醒其基础模型可能过度自信；本轮不以原始置信度作为正确概率，若要主张校准，须另收带真值的飞行场景决策集并做留出集可靠性检验。
- 连接组可以支持具体感觉运动回路的可检验预测，但接线图和简化神经元模型不自动给出完整自由飞行：[Shiu 等，Nature 2024](https://www.nature.com/articles/s41586-024-07763-9)。下行网络参与行为选择、启动和在线转向，为高层意图与低层运动通路的分工提供生物学参照；本项目的具体调制表仍是工程假设：[Braun 等，Nature 2024](https://www.nature.com/articles/s41586-024-07523-9)。
- 真实果蝇自由飞行包含快速转向，实验条件会改变转向统计；因此必须匹配场景和检测方法：[Stupski 与 van Breugel，Current Biology 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11461137/)、[Mronz 与 Lehmann，JEB 2008](https://doi.org/10.1242/jeb.008268)。

**最终交付形式**：一份冻结实验清单、一套可重复运行的场景/控制器/日志/分析/回放合同、完整原始数据及逐假设报告。即便 H1–H4 均不通过，只要能定位是哪条接口断裂，本轮研究仍完成了目标。
