## 1. 研究问题与假设

**问题**:把「生物真实的感觉运动底层」和「机器学习的意图决策顶层」拼在一起,虚拟果蝇的行为能有多像真果蝇?

**假设**(实验计划,2026-09-24):最大似然校准的意图决策模型(Laya,System-1 choice 模型,本地 MLX 推理)+ 果蝇全脑连接组(166,700 神经元 LIF 仿真)组合,可逼近真实果蝇自由飞行行为;实验测定其拟真度上限。

**预注册的诚实预期**(计划 §5):MaleCNS 连接组论文验证的是网络统计量,不等于「驱动即得真实行为」;视觉抽象(R1-R6 亮度向量)和 DN 线性读出是强简化。实验的真实产出是**量化这条路径的天花板与失败模式**,而非证明必然成功。

## 2. 系统构造(FlyLaya)

```
3D 世界(1m³:障碍柱、阳光方向)
   │ 感官:复眼抽象 → R1-R6 亮度向量
   ▼
果蝇连接组全图 LIF(166,700 神经元,DOOMFLY Metal 内核,0.93× 实时,892MB/实例)
   │ 读出:下行神经元(DNp20_L/R 等)发放率
   ▼
运动映射:DN 差分 → 偏航/推力/俯仰 → 位姿积分(10Hz)
   ▲                        │ 每 200–500ms,状态编码为文本 state_text
   └── Laya 意图层(mlx-serve)◄
       choice ∈ {趋光, 避障优先, 探索巡航, 边界规避, 悬停休息} → 切换增益调制矩阵
       score = 唤醒度(arousal)→ 调制整体运动增益
```

代码:`flylaya/{server,world,brains,intent}.py`;批量 `m4/run_batch.py`;指标 `m3/trajectory_stats.py`。
硬约束:16GB 内存 → 全图实例串行或 ≤2 并发;40 段 300s 仿真串行约 3.6h。

**四消融配置**(归因设计):

| 配置 | 连接组 | 意图源 | 检验什么 |
|---|---|---|---|
| A_full | 全图 | Laya | 完整系统 |
| B | 全图 | 固定轮换 | Laya 的贡献 |
| C | 骨架 | Laya | 连接组的贡献 |
| D | 全图 | 随机 | 意图内容 vs 节奏 |

## 3. 实验设计:拟真度三口径

同一批 40 段数据(4 配置 × 10 种子 × 300s × 10Hz),三个独立口径判定:

1. **口径 1 轨迹统计 vs 文献**:saccade 率/幅值/时长/峰值角速度、速度 p50、直线段直度、rest 占比、空间占用等,与文献区间对照(`m3/literature_baselines.json`,7 项机读)
2. **口径 2 人类盲评**:3D 双视窗盲评页(Minecraft 风格方块世界,同对左右两段完整 300s 轨迹同步回放,可旋转缩放,界面无配置名/意图/数值)。每对双 5 点量表 + 强制二选一。20 对(A_full 20 次、B 14、C 3、D 3)。3 位评分者(csx/lee/xixi)独立完成
3. **口径 3 消融增益**:配置间两两 KS 检验 + 积分量差异 = 各组件贡献

## 4. 执行时间线(过程叙事)

**阶段 0 · 意图规范先行**(researcher):state 文本模板 v1 → 轮次验收中发现 Laya 零样本意图塌缩 → **v1.1**(前置性短语 in/off/not in the flight path、avoid 瞬时逃离偏置、30s 段验收 ≥4/5 类)。

**阶段 1 · M1–M4 主体**(pi-swarm 多 agent,2026-09-24):
- M1 世界+回路骨架(backend,7min 完成):3D 场地、R1-R6 编码、DN 映射、FastAPI+three.js 查看器
- M2 全图×Laya 闭环(backend):313 次调用 0 失败,p50 32.8ms,同 seed 位置级复现
- M3 评估三件套(tester):指标模块 + 文献基线 + 四消融 runner
- **事故① 自旋吸引子**:tester 差分实验坐实 connectome 系恒 344dps 自旋。根因:DNp20 读出紧张性左右失衡(零输入 L 8.0Hz / R 18.8Hz)。修复:增益 0.3 + 视觉不对称 DC 去除 → ω p50 **344→77dps**,>300dps 占比归零(TASK-0017)
- **事故② swarm 8h 决策死锁**:裁定请求以自定义事件广播,不产生可认领任务、不唤醒任何 agent → 全员 idle 8h06m。用户一条消息 30 秒解锁。根因已上报 pi-swarm#1(bug),修复建议:裁定定向路由 + coordinator 定时唤醒
- M4 批量:40/40 段零失败

**阶段 2 · 收口**(2026-09-25):3D 盲评页(frontend 从 Minecraft 风格观察器迭代)→ 3 评分者完成 → 三口径终报发布(TASK-0018 验收通过)→ 归档 myylaya git。

**阶段 3 · 迭代①**(终报后):意图切换率修复(spec v1.1 + tau=1.6 温度采样 + eps=0.06 非rest探索 + 逃离偏置,env 旋钮默认关)→ 确认批 3 种子×300s。

**阶段 4 · 文献基线复核**(researcher,TASK-0007):saccade 率文献区间从 INFERENCE 落成 VERIFIED——见 §6 修正。

## 5. 结果(全部定量)

### 口径 2 人类盲评(3 raters × 20 对,3D 盲评)

| 配置 | 被选率(合并) | 平均分(n) |
|---|---|---|
| **A_full** | **59/60 = 98.3%** | **4.22**(60) |
| B_no_laya | 1/42 = 2.4% | 1.55(42) |
| C_no_connectome | 0/9 | 1.00(9) |
| D_random | 0/9 | 1.33(9) |

分评分者:csx 20/20 选 A(4.20)、lee 20/20(4.55)、xixi 19/20(3.90)。一致性:Gwet AC1 = 0.966;两两 Cohen κ 最高 1.000;**Fleiss κ = −0.017 属 κ 悖论**(边际 98% 极端偏斜 → 机会一致率≈实际一致率,κ 失效;主读数用 AC1 与原始一致率,这是方法学处理不是数据问题)。显著性:A 被选二项检验 p = 5.3e-17;A−B 评分配对差 2.74 分,t(41)=18.4。

### 口径 3 消融增益(KS 检验)

- **A−B 可分离**:speed D=0.394、ω D=0.192、saccade 幅值 D=0.206(均 p<1e-3);rest 21%→1.4%、空间占用 32%→37%——Laya 在连接组之上产生可测的积分行为差异
- **A−D 与 A−B 幅度相近**(speed D=0.394;occ 0.37 vs 0.225)——信息主要来自意图序列存在与否
- **B−D 不可分离**(ω p=0.24、heading p=1.0)——连接组主导下,意图的内容与节奏都不构成差异源
- **C−其余最强分离**(speed/ω D=0.5–0.71)——连接组贡献最大
- A 内部 arousal-speed Pearson r=0.671(规范 >0.3 达标)

### 口径 1 文献对照

旧基线判定:全配置 1–2/7 项落入文献区间。具体偏离:saccade 率 0.05–0.07Hz(文献区间见 §6 修正);幅值 32–34° vs ~120°;speed 12–14cm/s vs 20–60;直度超区间;connectome 系趋光 sun_R≈0.03–0.04(skeleton 系 0.527——感官侧信息存在、读出侧丢失);z 恒 49cm(垂直反射钉中线,无垂直探索)。

### 迭代① 结果(意图切换率修复)

| 指标 | 修前 | 修后(3 种子×300s) |
|---|---|---|
| 意图切换率 | 0.0033Hz | **0.50–0.56Hz**(进 spec 0.1–1) |
| 意图分布 | 2/5 类(avoid 98.9% 塌缩) | 5/5(avoid 27–33%) |
| 自旋/arousal | — | ω 97–108dps、r 0.43–0.52,无回归 |

**代价(如实记录)**:A−B 运动学分离弱化——speed D 0.394→0.178,ω 与 rest 分离消失(新 A 的 rest 0.19–0.24 ≈ B 0.207)。根因:旧 A 的「超活跃」签名本身是 avoid 塌缩的产物(从不休息);意图分布变丰富后积分量向 B 收敛。**口径 2 的 98% 结论建立在旧 A 上,新 A 未重盲评**——新基线 40 段重批与新 A 重盲评正在进行(TASK-0001/0002)。

### 文献基线修正(2026-09-25 复核)

saccade 率文献区间从 [0.2, 2.0](无来源推断)修正为 **[1.0, 3.0]**(已验证):主源 Stupski & van Breugel 2024(Curr Biol 34(19):4397-4411.e6, PMC11461137 全文)——野生型自由飞行四条件均值 **1.8–2.1 Hz**,嗅觉激活搜索态 2.5–3.4,sink-and-circle 3–4 Hz@~60°。幅值带 [60,150°] 三源确认(Mronz 2008 ~120°、Tammero 2002 ~90°/<100ms、Stupski ~60°)。**含义:模拟 saccade 率对文献均值的差距从 ~4× 修正为 ~30×,口径 1 的欠账比终报原判更重**。速度 p50 [20,60] 与直度 [0.6,0.95] 仍为推断(有锚点、无实测分布,全文获取被出版商墙挡)。

## 6. 结果说明了什么(解释与边界)

**已可主张的**:
1. **相对拟真已证,且双口径互证**:Laya 意图层让行为在统计口径(口径 3)和人类感知口径(口径 2)都可分地更接近真蝇——98% 的人类选择率与 KS D 0.39 指向同一方向。人类分离比统计分离更极端:活动量/rest 这类积分量对观察者比逐帧分布更显著。
2. **架构归因清晰**:连接组决定运动学形态(C 最强分离、B≈D);Laya 的价值在增益调制改变积分行为处(活动量/空间利用/rest 压缩),而不在逐帧运动学。
3. **意图动态是可工程修复的**:塌缩(98.9% avoid)和切换率过低(0.0033Hz)都通过 state 编码 + 采样策略修复进 spec 区间,且护栏(自旋/arousal)不回归。

**不可主张的 / 边界**:
1. **绝对拟真度未达**:saccade 节律缺两个数量级(修正后差距 ~30×)、幅值仅为文献 1/4、速度仅 1/2、无趋光、无垂直探索。虚拟蝇「相对像 A 不像 B」,但「统计意义上还不太像真果蝇」。
2. **B−D 不可分离是个负结果**:连接组主导通路下,意图内容不产生行为差异——要让 Laya 的决策内容可见,必须让意图作用于非主导通路(如 thrust/yaw 噪声结构的调制深度),这是下轮迭代的核心设计命题。
3. **98% 盲评结论有过期风险**:迭代①改了 A 的行为分布,分离弱化后人类是否仍能 98% 识别,未经复验不得沿用。
4. **口径 1 的判定依赖基线版本**:基线已修正一次(saccade 率),引用历史达标数必须注明版本。
5. **κ 悖论提示**:极端偏斜任务下 Fleiss κ 无效,未来盲评预设主指标应为 AC1/原始一致率。

**方法论产出**(与行为学结论同等价值):自旋吸引子的完整根因链(DNp20 紧张性失衡 × 增益饱和);多 agent 科研协调的死锁模式与修复(裁定路由 + 定时唤醒);盲评一致性指标的适用性边界。

## 7. 失败模式清单(根因链)

1. 自旋吸引子(已修复):DNp20 读出偏置 × YAW_GAIN=1.6 饱和 → 344–550dps 旋转;修复后 77dps
2. 意图塌缩(已修复):Laya 对 avoid 零样本高置信 + state 变化慢 → 98.9% 单类;v1.1 前置短语 + 采样旋钮修复
3. 意图切换率过低(已修复,有代价):见 §5 迭代①
4. saccade 节律缺失(未修):yaw 映射无快速瞬态或 DN 读出时间常数过长
5. connectome 无趋光(未修):亮度→DN 映射丢太阳方位
6. z 钉死 49cm(未修):垂直反射硬约束
7. B−D 不可分离(设计命题):意图需作用于非主导通路
