📋 项目概述

Pi Swarm 是一个零外部服务的多智能体协调运行时——同一工作区内的多个独立 Pi 会话，通过共享拉取式任务池、原子文件认领、追加式 JSONL 事件流和 Markdown 黑板，以专职角色协作完成工作。没有监督 LLM，没有代理之间的直接调用——一切协调都发生在 .pi/swarm/ 目录下的文件里。

🎯 任务池

  • 拉取式·非推送
  • O_EXCL 原子认领
  • YAML + Markdown 持久化
  • 竞争 already_claimed = 正常

  • 单写者 JSONL
  • at-least-once 消费
  • 按字节游标
  • 事件≠所有权

📝 黑板

  • Markdown 共享知识
  • 按角色 glob 策略
  • 读写权限强制
  • 决策/发现/评审

🔄 恢复

  • 心跳过期+进程死亡双条件
  • 孤儿任务自动回收
  • /swarm doctor 诊断
  • /swarm recover 修复

任务状态机

open ──原子认领──▶ claimed ──显式start──▶ in_progress ──▶ done | failed │ │ ▲ │ ▼ │ 义务完成自动恢复 │ blocked ──▶ abandoned ──▶ open

拓扑感知调度 (Boundary Gate)

硬约束(能力/排除) → Primary专家在线? → 只允许Primary └▶ 无Primary,Secondary在线? → 只允许Secondary └▶ 都无且允许fallback → 回退池 └▶ 否则 → UNSERVICEABLE(显式暴露,绝不静默)
